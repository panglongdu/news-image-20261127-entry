Entry for the [make.fun bounty news-image-20261127](https://make.fun/bounty/news-image-20261127): sum up 27 November's world news in one image.

`build_image.py` draws a 1024×1024 front page with Pillow — deep-navy broadsheet with amber and red accents, a dominant lead story on the Trump–Putin deal talk, a drawn globe panel, a four-cell stat band, two-column lower stories and a bottom ticker. `main.py` copies the built `entry.png` into `MAKEFUN_OUTPUT_DIR` (or `/output`).

## Run it

```sh
python3 build_image.py
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
